# Banco de Dados I — UFU

Repositório com projetos acadêmicos desenvolvidos na disciplina de **Banco de Dados I** do curso de **Sistemas de Informação da Universidade Federal de Uberlândia (UFU)**.

Os trabalhos abordam desde a **modelagem de banco de dados relacional** até a elaboração de **consultas SQL em PostgreSQL**, aplicando conceitos fundamentais de organização, relacionamento e recuperação de dados.

## Projetos

### Trabalho 1 — Modelagem de Banco de Dados

Desenvolvimento da modelagem de um banco de dados para uma aplicação de relacionamento entre usuários.

O modelo contempla diferentes entidades e relacionamentos, incluindo:

- Usuários
- Planos
- Fotos
- Interesses
- Perguntas e respostas
- Likes e dislikes
- Matches
- Mensagens privadas
- Grupos de relacionamento
- Mensagens em grupo
- Bloqueios

O trabalho envolveu a definição de entidades, atributos, relacionamentos, chaves e tipos de dados, além da construção do diagrama relacional utilizando **MySQL Workbench**.

📁 Arquivos disponíveis em `trabalho-1-modelagem/`

---

### Trabalho 2 — Consultas SQL em PostgreSQL

Desenvolvimento de **14 consultas SQL** sobre uma base de dados de uma locadora.

As consultas envolvem informações sobre:

- Filmes
- Clientes
- Atores
- Diretores
- Empréstimos

Entre os conceitos utilizados estão:

- `SELECT`
- `WHERE`
- `ORDER BY`
- `LIKE`
- `UNION`
- `JOIN`
- Múltiplos `JOINs`
- `COUNT`
- `AVG`
- `SUM`
- `GROUP BY`
- `HAVING`
- `EXTRACT`
- Self Join
- Relacionamentos entre tabelas

📁 Arquivos disponíveis em `trabalho-2-consultas-postgresql/`
